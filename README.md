# 银霜桌宠

银白长发、紫水晶眼眸的龙族御姐，气质高贵、冷静、睿智。

当前提供 **v0.1.0-preview 基础动作试用版**。完整 v2 仍在制作；这两个版本分开保存。

## 试用范围

- 九组动作：待机、向右移动、向左移动、挥手、跳跃、受挫、等待输入、工作思考、审阅。
- 采用 1536×1872、8×9 的 v1 兼容图集，包 ID 为 `silver-dragon-preview`，名称为“银霜·试用版”。
- 尚无 16 向视线追踪。面部精细度受 192×208 单格尺寸限制。
- 图集通过格式、透明背景和去色溢出检查；应用内首次加载仍需实际确认。
- 试用现有本地动画无需调用生图 API。后续制作新图才需要独立生图密钥。

## 安装与选择

在项目根目录用 PowerShell 运行：

```powershell
& .\scripts\install-preview.ps1
```

安装脚本会核对包内 SHA-256，将两个必要文件复制到 Codex 用户目录的 `pets/silver-dragon-preview`。它不会修改对话配置。若同名试用包已有不同内容，会先在本项目 `.local/install-backups/` 中备份。

安装后打开 **设置 → Pets → Refresh**，选择 **银霜·试用版**。需要显示悬浮宠物时可使用 `/pet`。若列表没有刷新，重启应用后再查看。请记录首次加载是否成功；文件验证通过不等于已经验证应用运行。

恢复原形象：在 Pets 中重新选择之前使用的宠物。完整 v2 将使用另一个包 ID `silver-dragon`。

官方说明：https://developers.openai.com/codex/pets

## 项目文件

后续开发以本仓库的 `production/run/` 为准。原始工作目录 `.codex/pet-runs/silver-dragon` 保留作本机历史备份，避免同时在两处修改导致进度分叉。

## 用 Git 保存

建议创建独立的**私有仓库**。Git 能保存代码、提示词、素材和任务断点；新对话可读取 `RESUME.md` 恢复工作，它不会自动获得旧对话内容。

提交已认可的素材和包即可；密钥、`.env`、临时文件、安装记录及失败大图不应提交。当前单个文件约 2.1 MiB，尚不需要 Git LFS。后续持续积累大量图片版本时，可再评估 LFS 或单独保存历史素材。

远程仓库：https://github.com/zhu574/Aipet-SilverDragon

主分支为 `main`，试用版标签为 `v0.1.0-preview`。初始代码、素材及任务断点已推送。继续开发前先阅读 `RESUME.md`；记录体验时更新 `FEEDBACK.md`。

当前电脑已在本仓库设置 Git 的网络兼容选项与系统代理，未改动全局配置。换电脑后需使用新电脑自己的网络配置。
